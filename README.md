# QuickNotes

QuickNotes is a small note-taking app for saving thoughts in personal, work, or study categories. Notes can be searched, edited by deleting and re-adding, and they stay saved in the browser between visits.

## Features

- Add and delete categorized notes
- Validate empty notes and the 200-character limit
- Search notes by one or more words
- Save notes in browser local storage
- Clear all notes after confirming

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser, or use the Live Server extension in VS Code.
3. Add a note and refresh the page to confirm it stays saved.
